Description

The Intergroup randomised trial led by the North Central Cancer Treatment Group and the Mayo Clinic: 929 patients with resected stage C colon cancer randomised to observation, levamisole, or levamisole plus fluorouracil, with tumour features and time to recurrence and to death.

A landmark adjuvant chemotherapy trial and a standard example for Cox models with recurrence and death as two outcomes per patient.

Known issues

Read these before analysis.

  1. Demonstration entry. Taken from the BioBench R package to show how HDR presents a dataset. It has not gone through HDR review and will be removed before launch.
  2. Two rows per patient, one for recurrence (etype 1) and one for death (etype 2). Count patients with id, not rows.
  3. nodes and node4 disagree for some patients. The survival package keeps both as received because the correct value is unknown.
  4. Missing values in nodes (36 rows) and differ (46 rows).
