Description

Patients with primary biliary cholangitis seen at the Mayo Clinic, 1974 to 1984: the 312 participants of the randomised trial of D-penicillamine versus placebo and 106 eligible patients who were followed but not randomised, with laboratory values and survival.

The reference dataset for the Mayo risk score and a standard example for Cox and competing-risk models.

Variables

One row per patient

Variable Type Description
id integer Patient identifier
time integer Days from registration to death, transplant or end of follow-up
status integer Status at end of follow-up (0 censored, 1 transplant, 2 dead)
trt integer Treatment (1 D-penicillamine, 2 placebo, missing not randomised)
age number Age (years)
sex string Sex (m, f)
ascites integer Ascites (1 yes, 0 no)
hepato integer Hepatomegaly (1 yes, 0 no)
spiders integer Spider angiomas (1 yes, 0 no)
edema number Oedema (0 none, 0.5 untreated or controlled by diuretics, 1 despite diuretics)
bili number Serum bilirubin (mg/dL)

albumin number Serum albumin (g/dL)
copper integer Urine copper (ug/day)

Known issues

Read these before analysis.

  1. Demonstration entry. Taken from the BioBench R package to show how HDR presents a dataset. It has not gone through HDR review and will be removed before launch.
  2. Rows 313 to 418 were not randomised (trt is missing) and have more missing values.
